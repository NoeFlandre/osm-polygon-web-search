# OSM Polygon Web Search

This public Hugging Face dataset contains one explicitly approved POC review
artifact at `poc/run.json`. It records the selected polygon, requested and
executed queries, search-result metadata, HTTP status, Trafilatura extracted
text lengths, and criterion-level evidence sentences.

The source PBF and local working artifacts stay under:

    /Volumes/Seagate M3/projects/osm-polygon-web-search

The uploaded artifact does not contain the local PBF, raw HTML, provider
response, or full page text. Raw web content is not published to Hugging Face.
The Apache-2.0 license applies to the project’s original code and
documentation; OSM-derived fields and web-derived evidence retain their
source-specific terms and should not be treated as Apache-2.0 content.
